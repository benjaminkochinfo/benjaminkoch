Researchers from Alibaba and several Asian universities built Co-Design Bench from real user change requests to existing web apps, favouring cases where users had to rephrase or roll back [1]. The best of ten models tested met about 70% of a task's requirements on average but was fully correct on only 26.4% of tasks, and on just under 18% of repository tasks [1]. Older benchmarks, by contrast, show scores above 99% for agents that can run and fix their own code [1]. The same model scored 75% or 56% on larger overhauls depending on the harness it ran in, so the authors recommend reporting model and working environment together [1]. The test has limits: one fixed request per task, and AI judges that can err [1]. For you: the last 30% of a job is still where the human invoice sits.
